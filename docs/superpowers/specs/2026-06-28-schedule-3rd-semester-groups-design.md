- Старое расписание 110 группы **полностью удалить**.

## Структура данных — `src/data/schedule.js`

`schedule` (один объект дней) заменяется на `schedules` по группам:

```js
export const GROUPS = ['Л-209', 'Л-210']
export const DEFAULT_GROUP = 'Л-209'

export const schedules = {
  'Л-209': { monday: [...], tuesday: [...], wednesday: [...], thursday: [...], friday: [...] },
  'Л-210': { ... },
}
```

`DAYS` остаётся без изменений.

Формат урока тот же: `{ time, subject, type, room?, dateFrom?, dateTo?, specificDates? }`.
В исходном файле **нет преподавателей** — поле `teacher` отсутствует. LessonCard
должен корректно отображать урок без преподавателя.

### Тайм-слоты

Файл использует время вида `08.50–10.25` и сдвоенные `08.00–09.35 / 09.45–10.30`.
В коде формат `HH:MM–HH:MM` (через en-dash `–`). Точки заменяются на двоеточия,
сдвоенный слот сохраняет ` / `.

### Чётность недель → конкретные даты

Где в файле указана «неделя: 1» или «неделя: 2» без явного списка дат,
разворачиваем в `specificDates` по понедельникам семестра:

- **Неделя 1** (Пн): 14, 28 сен; 12, 26 окт; 9, 23 ноя; 3, 21 дек.
- **Неделя 2** (Пн): 7, 21 сен; 5, 19 окт; 2, 16, 30 ноя; 14 дек.

Для других дней недели даты сдвигаются от понедельника соответствующей недели
(Вт = +1, Ср = +2, Чт = +3, Пт = +4). Где в файле уже даны явные даты
(`даты: «10, 24 ноября…»`), используются они напрямую.

`специфические даты` хранятся как `YYYY-MM-DD`.

## Переключатель групп и состояние

- Состояние `group` поднимается в `App.jsx`: `useState(() => localStorage.getItem('group') || DEFAULT_GROUP)`.
- Сохранение в `localStorage` при изменении (`useEffect`).
- `group` передаётся в `Header`, `HomePage`, `SchedulePage`.
- `Header`: текст «110 группа» заменяется на сегментированный переключатель
  `Л-209 | Л-210` (две кнопки-пилюли, активная подсвечена).

## Утилиты времени — `src/utils/time.js`

Убрать прямой импорт `schedule`. `getLessonsForDate` принимает расписание дня
параметром, чтобы не знать о выбранной группе:

```js
export function getLessonsForDate(dayKey, date, daySchedule) {
  return (daySchedule || []).filter((l) => isActiveOn(l, date))
}
```

Компоненты передают `schedules[group][dayKey]` (или `schedules[group]` целиком,
по месту использования). `getTodayKey`, `getWeekDate`, `parseMinutes`,
`getStartEnd`, `isActiveOn`, `getCurrentIndex`, `getNextIndex` не зависят
от расписания — без изменений.
